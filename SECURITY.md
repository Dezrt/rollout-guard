# Безопасность

Если проблема может быть уязвимостью, не нужно публиковать её в обычном issue.
Лучше отправить приватный отчёт через вкладку **Security** на GitHub и указать
затронутую версию, способ воспроизведения и возможные последствия.

Rollout Guard читает учётные данные Prometheus только из переменной окружения,
имя которой задаётся через `bearer_token_env`. Bearer-токены, Kubernetes
Secrets и production-URL с учётными данными не должны попадать в репозиторий.

Контейнер и Helm chart рассчитаны на запуск без root: корневая файловая система
доступна только для чтения, Linux capabilities сброшены, повышение привилегий
запрещено, ServiceAccount-токен не монтируется.
